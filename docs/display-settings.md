# 显示设置预览

进入 DSH 设置 → 费用 → 显示。预览分为侧栏、输入区和会话内容三个区域，使用正常字号，只渲染当前区域。点击组件的虚线框，在右侧调整可见性、内容和样式。未显示的侧栏组件以淡色标签保留入口；右侧的组件选择菜单也可访问它们。更改自动保存。

右侧直接展示简洁、标准和紧凑三种样式的小预览，复用实际预算与多时段额度的进度卡片。小预览标记为样式示例，未配置的额度使用本地示例数值。紧凑样式将多时段额度排成两列，预算卡片保持完整。点击峰谷条可切换细条或分段样式；点击“今日金额 · 模型数”可调整模型卡片的展开、周期、摘要、位置、行数、Token 和费用占比条。预算、余额、会话费用和额度条的选项各自放在对应组件旁。金额格式、换算和语言集中在下方。宽窗口将样式缩略图横向排列，窄窗口再改为竖向；右侧面板在空间不足时排到预览下方。放大预览中按 Escape 返回。

侧栏预览和真实侧栏共用完整的呈现函数与当前缓存数据，包含余额错误状态、Go 与预算合并卡、预算内的今日用量和峰谷条、模型花费卡片。选择框使用独立覆盖层，不改变组件 DOM 层级和紧凑布局。打开时最多读取三个宿主表面的背景、圆角、字体等六项外观属性；主题属性变化时更新。共用插件组件、DSH 图标和主题变量，跟随这些外观的皮肤修改；其他插件的独立控件不重复挂载。

侧栏读取当前数据，输入区与会话内容仍使用本地示例。预览不复制会话内容，不遍历整页 DOM，不创建 iframe，不解码图片，不订阅会话投影或额外查询账户、额度。选择框只测量当前预览内最多 32 个标记节点，使用一个局部尺寸监听器；关闭时清理尺寸与主题监听器。异常组件由预览内部的错误边界隔离，仍可使用详细显示选项。

预算显示和预算统计分别控制。隐藏预算卡片不会关闭预算统计；隐藏峰谷条不会关闭峰谷计价；显示 Go 占位不会启用账户查询。
