# 按渠道设置模型价格

在“设置 → 费用 → 价格”的模型匹配列表中，打开对应模型的下拉框，选择“自定义价格（此渠道模型）”。

输入、缓存读取、输出价格放在同一组，单位为每百万 Token，可选 USD 或 CNY。缓存写入和单独推理费用放在“更多计费项”中。推理已包含在输出价格中时无需另填；缓存写入留空则使用缓存读取价格。

倍率复用价格卡片原来的操作：输入 `2 × 0.8`、`2 * 0.8` 或 `2 x 0.8`，按回车或离开输入框后保存。默认将倍率应用于这个模型的全部单价；勾选“分别设置倍率”后可单独修改各项。实际单价在表单下方显示。

例如渠道 A 的输入价格为 `2 × 0.8`，实际为 1.6；渠道 B 的同一模型设置 `2 × 0.5`，实际为 1。原价不会被反复相乘。

设置按 DSH 的渠道 ID 和模型 ID 保存。两个接入渠道需要使用不同的渠道 ID。自定义价格不修改公共价格表，也不参与其他渠道的自动匹配。切回自动匹配或价格表条目后，填写过的自定义价格保留，再次选择即可继续使用。

价格和倍率只影响后续调用，历史记录继续使用当时的版本。历史重算仍由价格页的独立入口明确触发。
