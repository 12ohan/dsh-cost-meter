# 显示设置预览

进入 DSH 设置 → 费用 → 显示，直接点击界面中的费用、余额、预算或峰谷项目。隐藏后保留淡化占位，再次点击即可显示；更改自动保存。放大预览支持键盘操作，按 Escape 返回设置。

在已打开会话的桌面端，预览优先复制当前页面已经渲染的 DOM、滚动位置和最终计算样式，因此会包含已启用皮肤和其他插件的界面效果。切换主题时自动更新；其他插件改变布局后可点击“刷新当前界面”。隐藏或尚未配置的项目使用淡化示例，插入实际页面的对应区域。没有可读取的会话页时，使用 DSH 0.2.0-rc.2 原生布局示例。

预览是内存中的静态副本，不再次挂载会话组件或其他插件，不发送聊天消息，也不请求账户、余额或推理接口。副本中的控件不会执行原页面的动作；外层点击仅修改显示设置。复制内容不会写入账本、缓存或上传。跨域媒体、嵌入网页和视频中的交互内容不重新加载。

预算显示和预算统计分别控制。隐藏预算卡片不会关闭预算统计；隐藏峰谷条不会关闭峰谷计价；显示 Go 占位不会启用账户查询。详细设置仍保留金额格式、刷新频率和布局选项。

原生图标与部分展示 CSS 的来源和许可证见仓库根目录 THIRD_PARTY_NOTICES.md。
