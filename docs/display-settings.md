# 显示设置预览

进入 DSH 设置 → 费用 → 显示。预览放在页面最上方，分为侧栏、输入区和会话内容三个区域，使用正常字号，只渲染当前选中的区域。点击费用、余额、预算或峰谷项目可切换显示；隐藏后保留淡化占位，再次点击即可显示。更改自动保存。

侧栏里的“样式”按钮可切换简洁、标准和紧凑布局，以及峰谷条的细条或分段样式。放大预览中按 Escape 先收起样式面板，再退出预览。模型花费设置和详细选项默认收起。

预览复用插件的预算、余额、Go 额度和峰谷展示组件，以及 DSH 原生图标和主题变量。打开时最多读取三个宿主表面的背景、圆角、字体等六项外观属性，以适配当前皮肤；主题属性变化时更新这些属性。其他插件对主题和这三个表面外观的修改会跟随，其他插件的独立控件不重复挂载。

预览使用本地示例数值，不复制会话内容，不遍历整页 DOM，不创建 iframe，不解码图片，也不发起账户或模型请求。关闭时清理主题监听器。异常组件由预览内部的错误边界隔离，仍可使用详细显示选项。

预算显示和预算统计分别控制。隐藏预算卡片不会关闭预算统计；隐藏峰谷条不会关闭峰谷计价；显示 Go 占位不会启用账户查询。

原生图标的来源和许可证见仓库根目录 THIRD_PARTY_NOTICES.md。
